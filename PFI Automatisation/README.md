- Remise finale : 17 décembre 2026 à 23 h 30

## Description du projet

Ce projet consiste à automatiser l'unité d'aspiration
du granudoseur à l'aide d'un automate Micro850,
de modules POINT I/O et d'une interface PanelView 800.

## Objectifs

- Configurer la communication EtherNet/IP.
- Concevoir les GRAFCET du système.
- Programmer les séquences en Ladder (LD).
- Développer une interface HMI.
- Gérer les modes manuel et automatique.
- Gérer les arrêts et les interlocks.
- Gérer la saisie des niveaux et du poids.
- Enregistrer les 10 derniers relevés.
- Tester et valider le fonctionnement du système.

## Logiciels utilisés

- Automation Studio : conception des GRAFCET.
- Connected Components Workbench : programmation
  de l'automate et développement du HMI.
- Visual Studio Code : documentation.
- Git et GitHub : gestion des versions.
